UX decisions recorded during planning (#439)

  • V1 stores validated default parameters at assignment time; custom per-portfolio parameter editing is deferred.
  • Changing the Strategy recalculates the screen immediately but sends no immediate email — the next successful daily scan uses the then-current assignment.
  • Held security without usable evidence fails safe to Hold with an evidence warning; a non-held security without usable evidence is never a Buy.
  • Email dispatch is idempotent per (portfolio, published analysis run_id) — retrying the same run cannot send duplicates.
  • Group order is fixed: Sell → Hold → Buy, on both the screen and the email, from the same typed recommendation result.
