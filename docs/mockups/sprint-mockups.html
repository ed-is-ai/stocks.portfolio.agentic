  • #7 is the critical path for #8 and #9. Capture fails silently: prepare_for_run returns nothing if the previous month already has a snapshot, which the #23 recovery created for every month up to 2026-08. It also returns nothing unless the run lands on the single eligible capture date after the close. All 1,217,809 stored scan records are reconstructed and bau_run_authority is empty.
