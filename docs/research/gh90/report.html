Reading the comparison

Minervini upgrades lowered ending value and worsened drawdown, while increasing turnover and reducing Sharpe. Weinstein upgrades raised ending value and CAGR, but drawdown worsened and Sharpe fell slightly; turnover rose sharply. The rule improved return in this survivor-universe test but did not improve every risk measure.

The same fixed 755-security survivor roster was used in all arms. The ON/OFF differences are comparable under the pinned inputs, but absolute performance is subject to survivorship bias and is not a point-in-time universe result.
