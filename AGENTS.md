# Project instructions

This repository uses BMAD Method 6.10.0. The canonical BMAD workflows are in
`_bmad/`, and generated planning and implementation artifacts are in
`_bmad-output/`.

When implementing work, inspect the active story in
`_bmad-output/implementation-artifacts/`, its specification and context, and
the relevant BMAD `SKILL.md` before changing code. Follow the story acceptance
criteria, run the repository tests and quality checks, and report changed
files, checks run, and deferred work.

Use `_bmad-output/implementation-artifacts/sprint-status.yaml` to determine the
next story. BMAD artifacts are the source of truth for implementation scope.

Make sure you track bmad features, stories as Github issues and their progress to allow visibility outside of codex
