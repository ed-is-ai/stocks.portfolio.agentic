# Extraction Specification

> Generated by spec-gen v1.0.0 on 2026-05-10 22:19

## Purpose

Fetches institutional holdings data from WisdomWise heat map API and extracts top-ranked stock
tickers for analysis pipeline

## Requirements

> `agents/extraction/extraction_agent.py`

### Requirement: ExtractTopTickers

The system SHALL fetches heat map data and returns top n tickers ranked by institutional overall_rank

#### Scenario: SuccessfulExtraction
<!-- spec-gen-test: tags=smoke (auto) -->
- **GIVEN** WisdomWise API is accessible and returns valid heat map data
- **WHEN** run is called
- **THEN** Returns up to TOP_N ticker symbols sorted by overall_rank

#### Scenario: APIFailure
<!-- spec-gen-test: tags=regression (auto) -->
- **GIVEN** WisdomWise API is unavailable or returns invalid data
- **WHEN** run is called
- **THEN** Returns empty list and logs error

#### Scenario: EmptyHeatMap
- **GIVEN** API returns valid response but no stock data
- **WHEN** run is called
- **THEN** Returns empty list and logs warning

### Requirement: FetchHeatMapData

The system SHALL makes http request to wisdomwise heat map api and parses json response

#### Scenario: ValidAPIResponse
<!-- spec-gen-test: tags=smoke (auto) -->
- **GIVEN** API returns JSON with children array
- **WHEN** _fetch_heat_map is called
- **THEN** Returns list of stock data and sets last_quarter

#### Scenario: InvalidResponseFormat
<!-- spec-gen-test: tags=regression (auto) -->
- **GIVEN** API returns JSON without children key
- **WHEN** _fetch_heat_map is called
- **THEN** Raises ValueError with response shape details

### Requirement: SaveInstitutionalContext

The system SHALL persists institutional filer increase/decrease counts and rankings to context file

#### Scenario: ContextSavedSuccessfully
<!-- spec-gen-test: tags=smoke (auto) -->
- **GIVEN** Valid ranked stock data with filer counts
- **WHEN** _save_ww_context is called
- **THEN** Writes JSON file with ticker-keyed institutional metrics

### Requirement: UpdateExtractionResults

The system SHALL appends new tickers to persistent results file under dated source groups

#### Scenario: NewTickersAdded
<!-- spec-gen-test: tags=smoke (auto) -->
- **GIVEN** Tickers not present in existing extraction results
- **WHEN** _update_results is called
- **THEN** Creates dated group and adds tickers to results file

#### Scenario: NoNewTickers
- **GIVEN** All tickers already exist in extraction results
- **WHEN** _update_results is called
- **THEN** Returns 0 without modifying results file

#### Scenario: ResultsFileMissing
<!-- spec-gen-test: tags=smoke,regression (auto) -->
- **GIVEN** extraction_results.json does not exist
- **WHEN** _update_results is called
- **THEN** Creates new results file with dated group
