## Purpose

A multi-agent stock analysis system that screens stocks using CANSLIM methodology, tracks
institutional flows, detects market tops, and manages trading portfolios. It automates the complete
investment workflow from stock discovery through analysis to trade execution and portfolio
management.

This system is organized into the following domains:
