### Requirement: CLIStock

The API SHALL support `CLI python3 screen_canslim.py` to screen us stocks using william o'neil's canslim methodology to identify investment candidates

**Request:**

```json
{
  "api-key": "string",
  "max-candidates": "integer",
  "top": "integer",
  "output-dir": "string",
  "universe": "array of strings"
}
```

**Response:**

```json
{
  "json_file": "string",
  "markdown_file": "string",
  "results": {
    "type": "array",
    "items": {
      "symbol": "string",
      "company_name": "string",
      "sector": "string",
      "market_cap": "number",
      "price": "number",
      "composite_score": "number",
      "c_score": "number",
      "a_score": "number",
      "n_score": "number",
      "s_score": "number",
      "l_score": "number",
      "i_score": "number",
      "m_score": "number",
      "passes_thresholds": "boolean"
    }
  }
}
```

#### Scenario: ScreenDefaultS&P500Stocks
- **GIVEN** Valid FMP API key and default parameters
- **WHEN** python3 screen_canslim.py --api-key YOUR_KEY is executed
- **THEN** Generates JSON and Markdown reports with top 20 CANSLIM candidates from 40 analyzed stocks
- **AND** Each stock analyzed for all 7 CANSLIM components (C,A,N,S,L,I,M)
- **AND** Results sorted by composite score
- **AND** Market direction analysis included

#### Scenario: ScreenCustomStockUniverse
- **GIVEN** Valid API key and custom stock symbols
- **WHEN** python3 screen_canslim.py --api-key YOUR_KEY --universe AAPL MSFT GOOGL is executed
- **THEN** Analyzes only the specified stocks and generates reports
- **AND** Custom universe overrides default S&P 500 list
- **AND** All CANSLIM components calculated for each symbol

#### Scenario: LimitAnalysisForFreeTier
- **GIVEN** Free tier API key with 250 calls/day limit
- **WHEN** python3 screen_canslim.py --api-key YOUR_KEY --max-candidates 35 is executed
- **THEN** Analyzes maximum 35 stocks to stay within API limits
- **AND** Prevents API quota exhaustion
- **AND** Still provides meaningful screening results
