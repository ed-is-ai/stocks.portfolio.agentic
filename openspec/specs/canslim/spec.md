## Requirements

### Requirement: CANSLIMScoreValidation

The system SHALL validate CANSLIMScore according to these rules:
- Each component score must be between 0 and 2 inclusive
- Total score cannot exceed 14
- Missing fundamental data scores 0 for that component

#### Scenario: CalculateCANSLIMScore
- **GIVEN** Stock with fundamental data available
- **WHEN** CANSLIMScore is calculated
- **THEN** Each component receives score based on O'Neil methodology thresholds
