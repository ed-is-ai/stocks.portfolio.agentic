# Analyst Specification

> Generated by spec-gen v1.0.0 on 2026-05-10 22:19

## Purpose

Analyzes stocks using CANSLIM fundamentals and Weinstein Stage Analysis momentum to generate
investment scores and recommendations.

## Requirements

> `agents/analyst/analyst_agent.py`

> Implementation: `analyze_stock` in `skills\canslim-screener\scripts\screen_canslim.py` · confidence: heuristic

The system SHALL processes a collection of stock records and generates analysis scores with buy-side recommendations.

### Requirement: ScoreStock

The system SHALL generates comprehensive stock analysis using canslim fundamentals and momentum technicals with 50/50 weighting.

#### Scenario: CompleteFundamentalAndTechnicalAnalysis
- **GIVEN** Stock record with complete price and fundamental data
- **WHEN** scoreStock is called
- **THEN** Returns StockAnalysis with CANSLIM score, momentum score, and technical indicators

#### Scenario: VCPPatternAnalysis
- **GIVEN** Stock with VCP pattern data available
- **WHEN** scoreStock is called with VCP data
- **THEN** Incorporates VCP analysis into momentum scoring and stop loss calculation

### Requirement: GenerateRecommendation

> Implementation: `recommendation` in `agents\analyst\analyst_agent.py` · confidence: llm

#### Scenario: StrongBuyRecommendation

- **THEN** Returns strong buy recommendation

#### Scenario: HoldRecommendation
