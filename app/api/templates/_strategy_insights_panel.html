Explain these backtests

Generate evidence-linked observations and research ideas from the displayed outcomes. The landing page does not contact a model.

What is sent to Claude when I submit?

A bounded summary of up to 25 verified results: Strategy ID and API version, tested periods and currency, scalar parameters, selected ticker symbols (at most 5,000 total), persisted metrics and availability, sample counts, provenance, benchmark status, cohort limitations, and exclusion counts. The request excludes run IDs, result URLs, profile hashes, starting capital, equity curves, trades, events, prices, full manifests, credentials, and portfolio data.
