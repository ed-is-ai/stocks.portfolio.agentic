Propose a test

When an Anthropic key is configured, Claude drafts proposals by default. Only the hypothesis, Strategy ID, declared parameter definitions, and current parameter values are sent to Anthropic. The baseline ID and manifest, Strategy source, other run inputs, and historical results stay in this app. If Claude is not configured, unavailable, or cannot return a schema-valid proposal, the app tries local Foundry with the same proposal context. Each proposal is then checked against the Strategy parameter contract; if it does not propose one valid declared parameter change, no draft is created.
